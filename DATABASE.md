# WGB — база данных и дополнительные услуги

Проект: https://github.com/kusainovascar/hotel

## Возможности
- Раздел «Дополнительные услуги» (данные из Supabase, резервный каталог до подключения).
- Выбор услуг при расчёте группового проживания.
- Отправка заявки менеджеру: группа или индивидуальный гость.
- Запись заявки в PostgreSQL через Supabase REST API, без права посетителей читать заявки.
- Excel-план сохраняет прежний механизм и не считается подтверждением брони.

## Подключение
1. Создайте проект на https://supabase.com и выполните `supabase/schema.sql` в SQL Editor.
2. В настройках проекта скопируйте **Project URL** и **publishable / anon key**. Не используйте `service_role` на сайте.
3. Заполните в `index.html` константы `SUPABASE_URL` и `SUPABASE_PUBLIC_KEY`. Это публичные ключи, их использование допустимо только с RLS.
4. Опубликуйте изменения на GitHub Pages после проверки. До настройки БД форма сообщает, что отправка недоступна; Excel продолжает работать.
5. Проверяйте заявки в Supabase → Table Editor → `leads`. Управлять статусами можно из защищённой панели Supabase.

## Оговорки для эксплуатации
- Каталог и тарифы являются **демонстрационными**. Сумма дополнительных услуг в автоматическую цену не включена; их рассчитывает менеджер.
- Наличие номеров и подтверждение бронирования **не проверяются**.
- Для публичного запуска добавьте Cloudflare Turnstile / CAPTCHA, защиту от массовых отправок на серверной стороне, политику обработки персональных данных, уведомления менеджеру и интеграцию с PMS/CRM.
- Никогда не публикуйте `service_role` или секретный API-ключ.
